## Alcance del sistema
El sistema contempla autenticación y roles, registro y actualización de lotes, historial de trazabilidad, movimientos de almacén, consulta de existencias, asociación de lotes a pedidos de exportación, alertas, reportes, auditoría y sincronización de operaciones offline.

## Estado de validación
El repositorio contiene la especificación, la matriz de trazabilidad, los diagramas y un plan de pruebas. Los casos de prueba figuran como pendientes; no se presentan como pruebas ejecutadas. Las mediciones de rendimiento, usabilidad y sincronización requieren validación práctica.

## Control de versiones
Los cambios de los artefactos se registran mediante el historial de commits del repositorio.
